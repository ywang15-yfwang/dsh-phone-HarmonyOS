dsh 手机端 · 隐私政策

更新日期：2026-10-26

一句话：不收集任何个人信息，没有账号，也没有我们自己的服务器。

1. 我们收集什么

不收集任何个人信息。

  • 不需要注册账号，没有账号体系；
  • App 没有自己的服务器，不会把使用数据、设备信息、位置、通讯录等上传到任何第三方；
  • 不接入广告、统计或推送 SDK。

2. 你的数据存在哪里

  • 电脑配置（设备名、端口、用户名）：只保存在手机本地；
  • 会话缓存与临时文件：只保存在 App 沙箱，可在「配置 → 清除临时文件」删除；
  • 配对凭据：只放在内存，不落盘；
  • SSH 密钥：由系统 HUKS 保护，只保存在本机。

3. 网络通信

手机与电脑之间的连接走 Tailscale 点对点加密网络，不经过本 App 的服务器。连接目标只能是你自己配置的电脑地址和端口，App 不会向其他地址发送数据。

4. 权限

权限用途
网络（INTERNET）连接你配置的电脑
VPN 扩展（系统授权）建立 Tailscale 隧道；首次使用由系统弹窗征求你的同意

文件选择、保存都通过系统文件选择器完成，不申请存储权限；不使用麦克风（语音输入由系统输入法提供）；不使用通知。

5. 数据删除

  • 删除某台电脑配置：App「配置」页 → 删除；
  • 清除临时文件：App「配置」页 → 清除临时文件；
  • 卸载 App 会删除本机全部数据；
  • 电脑侧数据由你自己在电脑上管理。

6. 第三方

App 内置 Tailscale 开源内核（BSD-3-Clause）用于建立网络连接；该内核只在你的设备与你的电脑之间工作，不向第三方传输数据。第三方软件声明见仓库的 THIRD_PARTY_NOTICES.md。

7. 联系方式

问题或建议请通过 GitHub Issues 联系：github.com/ywang15-yfwang/dsh-phone-HarmonyOS/issues

本政策可能随版本更新；更新后会在本页替换并修改「更新日期」。
