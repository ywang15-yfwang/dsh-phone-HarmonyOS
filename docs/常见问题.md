# 常见问题

**手机上显示「dsh 未启动」？**
先在电脑上确认 dsh 真的在跑；如果没跑，点「开启」。刚进页面时会先显示「检测中…」，探活失败会自动重试一次。

**连接失败？**
1. 手机和电脑是否都在 Tailscale 在线；
2. 电脑上的插件端口与 App 里填的「插件端口」是否一致；
3. 该端口的插件是否已经加载（重启 dsh 后再试）。

**点「开启」没反应 / 报启动失败？**
- 电脑必须**已登录桌面**：计划任务以登录用户身份运行，锁屏/未登录时拉不起来；
- 检查电脑端脚本是否按 `scripts/README.md` 安装好；
- 检查 App 里填的 dsh 端口和电脑上的实例端口一致。

**审批弹不出来？**
审批由「运行这场会话的 dsh」发出。电脑上开了多个实例时，手机要连到对应的那个；App 会自动尝试可用的实例。

**重装 App 后要重新登录？**
会。重装会重启进程，Tailscale 连接断开，需要在登录页重新点一次登录。

**手机能单独跑 dsh 吗？**
不能。dsh 始终运行在电脑上，手机只负责远程查看和操作。

**支持 iOS / Android 吗？**
目前只支持 HarmonyOS NEXT。

**数据会上传到哪里吗？**
不会。App 没有自己的服务器，不收集使用数据；手机与电脑之间走 Tailscale 加密通道。
