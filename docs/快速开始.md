# 快速开始

## 0. 准备

- 一台 Windows 电脑，装好 dsh，并且**已登录桌面**（Windows 计划任务以登录用户身份运行，未登录时手机点「开启」也拉不起来；建议开启自动登录，见 `scripts/README.md`）。
- 手机上装好 Tailscale，并与电脑登录同一个账号（同一 tailnet）。

## 1. 电脑：安装插件

插件源码在本仓库 plugin/。

```powershell
# 在 dsh 的 profile 目录里 link 这个插件（示例，按你的 dsh 安装方式调整）
$env:CI='true'
cmd /c "pnpm --dir <profile目录> add link:<本仓库路径>/plugin --reporter=append-only"
```

把 `dsh-to-phone` 加进该 profile 的 `package.json` 的 `dsh.profile.bundles`，并在插件配置里填**必填**的 `port`（每个 dsh 实例各自一个端口，没有默认值）。

插件配置示例：

```yaml
- id: pair
  name: dsh-to-phone
  config:
    port: <你选的端口>        # 必填，1-65535
    # phonePort: <该实例的 dsh 端口>   # 可选：只在这个实例上绑配对口
    # artifactsDir: <工件目录>          # 可选：工件列表
```

重启 dsh 后，电脑上应能访问 `http://127.0.0.1:<port>/pair/info`。

## 2. 电脑：安装启停脚本

见 `scripts/README.md`。装好后，手机才能远程「开启 / 关闭 dsh」。

## 3. 手机：安装 App

- 自己构建：见 `docs/构建与签名.md`；
- 安装后打开 App，登录 Tailscale。

## 4. 手机：配置并连接

1. 「配置」页 → 已配置的电脑 → 添加/修改；
2. 填：设备名、dsh 端口（默认 3080，可改）、插件端口、SSH 端口、SSH 用户名；
3. 保存后回「电脑」页，选中电脑 → 连接。

## 5. 验收

- 电脑页能看到电脑在线 / 离线；
- 电脑上 dsh 已启动时显示「dsh已启动」；
- 点「连接」能进会话、收发消息；
- 点「开启」能在电脑上拉起 dsh（需要电脑已登录桌面）。
