# 构建与签名

本仓库**不包含任何签名材料**（证书、私钥、密码都不在仓库里）。构建/调试/上架前，请在本机配置自己的签名。

## 环境

- DevEco Studio / HarmonyOS SDK（API 26）
- 命令行构建工具 `devecocli`（或 DevEco 自带的 hvigor）
- 本机已连接 HarmonyOS 设备（可选，用于装机）

## 构建

```powershell
cd app
devecocli build
```

产物在 `app/entry/build/default/outputs/default/`。

## 签名（本地配置，不要提交）

1. 用 DevEco Studio 的「自动签名」或华为开发者后台生成自己的证书与 Profile；
2. 在本机 `app/build-profile.json5` 里加回 `signingConfigs`，例如：

```json5
app: {
  signingConfigs: [
    {
      name: 'default',
      type: 'HarmonyOS',
      material: {
        certpath: '<本机证书路径>',
        keyAlias: '<别名>',
        keyPassword: '<加密后的密码>',
        profile: '<本机 p7b 路径>',
        signAlg: 'SHA256withECDSA',
        storeFile: '<本机 p12 路径>',
        storePassword: '<加密后的密码>'
      }
    }
  ],
  products: [
    { name: 'default', signingConfig: 'default', /* 其余保持不变 */ }
  ]
}
```

3. 确认 `signature/`、`*.p12`、`*.p7b`、`*.cer`、`*.jks` 都在 `.gitignore` 里，**不要** `git add`。

## 装机与截图（开发用）

```powershell
devecocli run --skip-build
devecocli ui screenshot --path shot.png
devecocli ui layout
```

## 改版本号

`app/AppScope/app.json5`：

```json5
"versionCode": 7000000,
"versionName": "0.7.0"
```

发版时同步更新 `plugin/package.json` 的版本与 `docs/功能说明.md` 末尾的版本行。

## 原生桥（首次构建前必做）

App 依赖一个 Go 编译的原生库 `libtailscale_go.so`（Tailscale 内核）。仓库**包含源码**，但不包含这个 50 MB 级的二进制：

- 源码在 `app/native/go_bridge/`；
- 构建需要**打过 `tailscale-ohos.patch` 的 tailscale v1.86.5 源码**，放在与本仓库同级的工具链目录里（`go.mod` 的 `replace` 指向它）；
- 编译产物放到 `app/entry/libs/<abi>/`；
- 细节见 `app/native/go_bridge/README.md`。

没有这个 `.so` 时，ArkTS 部分能编译，但打包/运行会缺库。
